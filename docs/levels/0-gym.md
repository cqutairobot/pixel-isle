# M0 · 手感测试关（练习场）详细计划

> 对应 PLAN.md §9 的 M0。只有角色跑跳和基础动效，没有敌人、方块、生命值、对话和音乐。目的是让用户先确认手感和美术方向，确认后锁定数值，再开始做第 1 关。

## 1. 目标

- 用户能在浏览器里操作小满，在一块分成 7 个"站点"的训练场里，逐项体验跑、跳、落地、转身、镜头这些基本手感。
- 提供 3 套手感预设（A / B / C）、两种跑步方式（按住跑 / 自动奔跑）、镜头亚像素平滑的开关，让用户对比后选择。
- 把 PLAN.md §6 里和移动、跳跃、镜头、基础动效相关的条目全部做出来，并能用调试工具逐项检查。
- 顺便验证整套技术路线：Phaser 4、整数倍像素缩放、固定步长、代码绘制美术、ZzFX 音效、中文像素字体。

| 站点 | 位置（列） | 内容 | 测试什么 |
|---|---|---|---|
| ① 长跑道 | 2–57 | 56 格平地，起点在左侧 | 起步、松手停下、转身急停、跑步加速曲线、满速尘土、镜头前瞻 |
| ② 缝隙 | 58–131 | 依次是 2、3、4、5、6、7 格宽的坑，坑之间是 6–8 格宽的平台，每个坑前立牌子标宽度 | 跳跃距离、土狼时间（在平台边缘晚一点起跳）、跳跃缓冲；掉坑后自动回到最近的安全地面 |
| ③ 台阶 | 132–175 | 高 1、2、3、4、5 格的石台，各 4 格宽，彼此隔开 4 格，台前立牌子标高度 | 最高/最低跳、边缘辅助（4 格台勉强够得到）、5 格台够不到 |
| ④ 撞头走廊 | 176–215 | 天花板离地 2 格，天花板上开了 1 格和 2 格宽的洞，洞上方是第二层通道 | 撞头的手感、撞头修正（从 1 格小洞穿过去）、可变跳跃 |
| ⑤ 单向平台塔 | 216–235 | 6 层单向木板，每层间隔 3 格，左右交错 | 从下方跳穿木板、站上去、↓ + 跳 落下 |
| ⑥ 长坠落 | 236–260 | 从塔顶向右走出平台，掉到 18 格下的地面 | 最大下落速度、重落地（微震、粗尘土、重音效）、镜头纵向跟随 |
| ⑦ 楼梯 | 261–297 | 5 级上楼梯、平台、5 级下楼梯 | 连续小跳、轻点跳的手感 |

- 进入站点时，画面上方弹出站点名称和一句说明（见 §5）。
- 用 Q / E 可以在站点之间传送，方便反复测试。

## 3. 手感预设

单位：px（游戏像素）、px/s、帧（60 帧/秒）。1 格 = 16 px。A 就是 PLAN.md §6 里的初始值。

| 参数 | A 标准 | B 轻快 | C 厚重 |
|---|---|---|---|
| 走速 / 跑速（px/s） | 90 / 150 | 96 / 160 | 84 / 150 |
| 起步：0→走速（帧） | 6 | 4 | 10 |
| 走速→跑速（帧） | 24 | 16 | 36 |
| 松手停下：从走速（帧） | 5 | 4 | 9 |
| 转身减速倍数 | 2.0 | 2.5 | 1.6 |
| 空中加速度（相对地面） | 65% | 80% | 50% |
| 空中阻力（px/s²） | 300 | 450 | 180 |
| 最高跳（格） | 4.25 | 4.0 | 4.5 |
| 起跳到顶点时间（秒） | 0.36 | 0.32 | 0.40 |
| 满跑额外起跳速度（px/s） | 24 | 20 | 30 |
| 松开跳跃时上升速度乘数 | 0.5 | 0.45 | 0.55 |
| 顶点悬停阈值 / 重力乘数 | 40 / 0.5 | 30 / 0.6 | 50 / 0.45 |
| 下落重力乘数 | 1.8 | 2.0 | 1.5 |
| 最大下落速度（px/s） | 330 | 360 | 300 |
| 土狼时间 / 跳跃缓冲（帧） | 6 / 7 | 6 / 7 | 6 / 7 |
| 撞头修正 / 边缘辅助（px） | 4 / 3 | 4 / 3 | 4 / 3 |

- B 更接近"指哪打哪"的现代平台跳跃；C 惯性更大、滞空更长，更接近经典横版。
- 调参面板里能改所有参数，并可导出 JSON 发给 Claude。

## 4. 操作

**游戏操作**（与 PLAN.md §5.8 一致）：

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 | ←→ 或 A D | 左摇杆 / 十字键 |
| 下蹲（往下看）/ 抬头（往上看） | ↓ / ↑ 或 S / W | 下 / 上 |
| 跳（按住跳得更高） | Z、空格 或 K | A |
| 跑（按住） | X 或 J | X |
| 下穿单向平台 | ↓ + 跳 | 下 + A |

**练习场专用键**：Mac 键盘的 F1–F12 默认是亮度、音量等媒体键，要按住 fn 才能用，所以主要用字母和数字键，F 键只作为备选。

| 键 | 功能 |
|---|---|
| 1 / 2 / 3 | 切换手感预设 A / B / C |
| 4 | 自动奔跑 开 / 关 |
| 5 | 镜头亚像素平滑 开 / 关 |
| Q / E | 传送到上一个 / 下一个站点 |
| R | 回到起点 |
| H | 显示 / 隐藏操作说明 |
| M | 静音 / 取消静音 |
| \`（反引号，Esc 下面）或 F1 | 调试叠加层：碰撞盒、速度、状态、计时条、跳跃轨迹、按键显示、网格 |
| T 或 F2 | 调参面板 |
| G 或 F4 | 慢放：1 → ½ → ¼ |
| P 或 Esc | 暂停；暂停时按 N 逐帧前进 |

**URL 参数**：`?preset=B` 指定预设，`?station=3` 从第 3 站开始，`?scene=soundboard` 打开试听板。

## 5. 界面文字

M0 的界面文字（预设标签、站点提示、操作说明、调试信息）先用 DOM 叠加层显示，字体是 Fusion Pixel 12px，按游戏像素的整数倍放大，保证清晰。正式的画布内 UI（位图字库、对话框等）在 M1-b 做。

站点提示：

1. **长跑道**：试试起步、松手、转身；按住 X 跑步，跑满速会扬起尘土。
2. **缝隙**：2–7 格宽。走路约能跳过 3 格，助跑约能跳过 6 格；掉下去会自动回来。
3. **台阶**：1–5 格高。按住跳最高约 4.25 格，所以 5 格那块够不到。
4. **撞头走廊**：天花板很低，感受撞头；从顶上 1 格宽的小洞跳上去，可以测试撞头修正。
5. **单向平台塔**：从下面能直接跳上去；站在木板上按 ↓ + 跳 落下。
6. **长坠落**：从塔顶往右跳下去，感受最大下落速度、重落地和镜头跟随。
7. **楼梯**：一级一级小跳上去再下来，试试轻点跳。

## 6. 新系统与代码清单（已实现）

- **工程**：`package.json`（`dev` / `build` / `preview` / `typecheck` / `test` / `test:e2e` / `format`）、`tsconfig.json`、`vite.config.ts`、`playwright.config.ts`、`index.html`、`.prettierrc`
- **`src/sim/`**（纯逻辑，不引用 Phaser）：
  - `tuning.ts`：参数类型、A/B/C 预设、由跳跃高度推导重力和起跳速度
  - `input.ts`：输入帧（按住、本步按下、本步松开）
  - `grid.ts`：碰撞网格（空、实心、单向平台）
  - `body.ts`：整数坐标 + 亚像素余量的逐像素移动（Actor）
  - `player.ts`：主角控制器（全部手感规则）
  - `camera.ts`：镜头逻辑（前瞻、死区、平台吸附、窥视、边界、硬约束）
  - `events.ts`：事件类型
  - `world.ts`：组合以上模块，每步 `step(input)`；掉坑后回到安全地面
  - `level.ts`：ASCII 地图解析与通用图例
  - `math.ts`：`approach`、临界阻尼平滑等
- **`src/view/`**：
  - `heroView.ts`：选帧、挤压拉伸、转身、眨眼、脚步同步
  - `ribbon.ts`：帽带链式物理（Verlet）
  - `textures.ts`：生成精灵图集与瓦片集贴图（瓦片外扩 1px 防接缝）
  - `backgroundView.ts`：视差背景
  - `particles.ts`：粒子（对象池、帧动画）
  - `shake.ts`：创伤值震动
  - `spring.ts`：阻尼弹簧
  - `juice.ts`：把 sim 事件映射成粒子、震动和音效
- **`src/art/`**：
  - `palette.ts`：32 色调色板
  - `sprite.ts`：字符网格、部件拼合、光栅化
  - `hero.ts`、`props.ts`（牌子、数字）、`fx.ts`（粒子贴图）、`sheets.ts`
  - `terrain.ts`：按颜色规则生成 47 种连接形状的地形瓦片，以及单向木板
  - `background.ts`：天空渐变（有序抖动）、山丘、云层
  - `rng.ts`：带种子的随机数与坐标哈希
- **`src/audio/`**：`zzfx.ts`（ZzFX 合成器移植）、`sfx.ts`（槽位与候选）、`engine.ts`（AudioContext、总线、首次按键解锁、同时最多 4 个实例）、`soundboard.ts`（试听板）
- **`src/platform/`**：`display.ts`（整数倍缩放、Retina、信箱区）、`input.ts`（键盘和手柄转成输入帧）
- **`src/ui/`**：`motion.ts`（动效令牌）、`dom/gymUI.ts` + `dom/ui.css`（预设标签、站点提示、操作说明、调试信息、按键显示、暂停条）
- **`src/debug/`**：`overlay.ts`（碰撞盒、速度、轨迹、修正标记、网格）、`tuningPanel.ts`（lil-gui）
- **`src/scenes/`**：`BootScene.ts`（生成图集、等字体）、`GymScene.ts`（固定步长主循环、渲染插值、调试键）
- **`src/content/levels/gym.ts`**：练习场地图与站点
- **`tests/`**：`player.test.ts`（跳跃高度、加减速、急停、土狼时间、跳跃缓冲、撞头修正、边缘辅助、单向平台、掉坑复活、重落地、确定性）、`level.test.ts`（解析与练习场校验）、`purity.test.ts`（`src/sim` 不引用 Phaser/DOM）
- **`e2e/smoke.spec.ts`**：启动无报错、能移动、能跳、叠加层与说明面板、试听板
- **`scripts/`**：`preview-art.ts`（精灵放大预览）、`preview-scene.ts`（不开浏览器拼一张场景图）、`jump-metrics.ts`（跳跃度量）、`analyze-sfx.ts`（音效分析）、`png.ts`（最小 PNG 编码器）

## 7. 美术需求

- **调色板 v1**：32 色。
- **小满**：16×18。
  - 帧：待机 ×2（呼吸）、眨眼、跑 ×6、起跳、顶点、下落 ×2、落地（屈膝）、急停、下蹲、抬头。
  - 做法：用"部件拼合"生成，部件是帽子、头、身体、手臂、腿，各自有几种变体，保证各帧一致。
  - 帽带两尾：程序绘制。
- **练习场瓦片**：浅色石块地面（3×3 块加内角，自动拼接）；单向木板（左端、中段、右端）；牌子（木桩加数字板，数字 0–9 用 3×5 像素字）；箭头牌。
- **粒子**：尘土（3 种大小）、撞头火花、重落地的扬尘、回到安全地面时的"噗"。
- **背景**：天空渐变加抖动、远山、云（视差 0.1–0.4）；调试模式下叠加 1 格网格，方便量高度。

## 8. 音频需求

- **音效槽位**（每个 3 个候选）：跳、轻落地、重落地、脚步（2 种变体交替）、急停、撞头、回到安全地面、界面切换音（换预设、切开关）。
- **试听板**（`?scene=soundboard`）：
  - 列出所有槽位和候选，点击即可试听。
  - 选中的候选保存在浏览器里，练习场立刻使用。
  - "导出"会把选择复制成 JSON，发给 Claude 写进代码。
- 没有音乐（M1 才做音乐引擎）。

## 10. 交付后请用户回答

（同 PLAN.md §9 的 M0 问题清单。）

1. 起跳是否即时？轻点和按住的高度差是否明显、合适？
2. 滞空和下落是否干脆，不飘也不沉？
3. 起步、停下、转身是否顺手？更喜欢"按住跑"还是"自动奔跑"？
4. A / B / C 三种预设更喜欢哪个？或者希望往哪个方向调？
5. 镜头跟随舒服吗？亚像素平滑开和关，哪个好？
6. 是否认可主角造型、瓦片和配色的美术方向？
7. 音效听着顺耳吗？可以在试听板里直接选。

## 11. 风险与备选

| 风险 | 备选 |
|---|---|
| Phaser 4 在高分辨率画布 + 相机整数缩放下出现模糊、接缝或抖动 | 改用 384×216 画布 + CSS 整数放大（PLAN.md §2.3 的后备方案） |
| 主角只有 16×18，代码画出来不够可爱 | 先出预览图自检，多迭代几轮；用户不满意时，按 PLAN.md §2.6 讨论换方案 |
| 手感预设都不合用户口味 | 用调参面板直接调到满意，导出 JSON 后写进预设 |
| ZzFX 候选音效都不好听 | 继续生成新候选，或者暂时静音，不阻塞手感确认 |
