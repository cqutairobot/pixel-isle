## 3. 实体与参数

| 实体 | 规则 |
|---|---|
| 霜壳蟹 `k` | 碰撞盒 12×10，速度 30 px/s。走到边缘会掉下去，撞墙或撞到同伴会回头。进入镜头 3 格以内才开始活动 |
| 蓝钳 `K` | 霜壳蟹的换色版，在边缘回头，速度 36 px/s |
| 铃砖 `B` / `M` / `*` | 从下面顶：铃声，上弹 4 px、8 帧回落，吐出道具，然后变成暗色。B 出贝壳；M 出芒果；* 出太阳果。芒果和太阳果沿小弧线弹出、落地后停住 |
| 多次铃砖 `$` | 第一次顶之后 3 秒内可以连续顶，最多出 8 枚贝壳 |
| 隐藏铃砖 `?` | 平时看不见、不挡路，只有主角从下往上撞到时才出现并算作被顶。可以在实体表里指定里面的东西（海玻璃 ②） |
| 沙岩砖 `b` | 顶碎成 4 块碎片并扬起尘土，停顿 2 帧 |
| 砖顶上的东西 | 不管哪种砖被顶，砖顶上的敌人都会被顶飞打倒，贝壳会被顶出来收下 |
| 贝壳 `s` / 大贝壳 `S` | 分别算 1 枚、10 枚。0.5 秒内连续拾取时音高逐级升高 |
| 芒果 `m` | +1 心；满心时变成 3 枚贝壳 |
| 太阳果 | 8 秒无敌，碰到敌人直接净化，跑速 ×1.15，最后 2 秒闪烁，期间换成欢快的变奏音乐 |
| 海玻璃 `g` | 每关 3 枚，编号 ①②③。拾取的同时就存档。再玩这一关时，已找到的显示为半透明，仍然可以拾取，但不重复计数 |
| 检查点 `C` | 经过就激活：铃响、丝带展开、一圈光环、提示"已记录"。只会往前更新 |
| 终点 `G` | 走进铃门：铃响，小满摆出胜利姿势，镜头稍微推近，飘落叶彩带，然后进入结算 |
| 海水 `~` | 掉进去溅起水花，扣 1 心，0.6 秒后回到最近的安全地面，并有 60 帧无敌。掉出地图的规则相同，只是没有水花 |
| 风铃（实体） | 三只风铃的音高是 G4（大）、C5（中）、E5（小），碰到就响，每只有 20 帧冷却。最近 4 下依次是"大、小、中、大"时，海玻璃 ① 从木架上弹出来 |

**主角的战斗参数**（写在 `src/sim/tuning.ts` 的 `RULES`，PLAN §6.5 同步更新）：

- **生命**：3 颗心；辅助模式下 5 颗。
- **受击**：
  - 停顿 6 帧。
  - 击退：横向 120 px/s，纵向 180 px/s。
  - 12 帧不能操作。
  - 90 帧无敌闪烁（4 帧亮、4 帧暗）。
- **判定**：
  - 主角的受伤判定是 8×12。
  - 踩踏判定比敌人的伤害判定左右各宽 2 px。
  - 踩中的条件：主角正在下落，并且上一帧脚底不低于敌人的上半部。
  - 踩中后 4 帧内，不会被同一只敌人伤到。
- **踩踏**：
  - 停顿 3 帧。
  - 弹起速度：不按跳跃键 240 px/s；按住跳跃键约 440 px/s（PLAN 原定 380，调高后"踩蟹弹高"才能上 6 格高台）。
  - 连踩（中途不落地）时，答谢的贝壳依次是 1、2、3、4、5 枚，最多 5 枚，音高逐级升高。
- **敌人被打倒**：冰晶碎裂，螃蟹变回原本的橙红色，眨眨眼，蹦跳着跑出画面；答谢的贝壳飞向 HUD。
- **死亡**：
  - 演出：定格 12 帧 → 画面去色，小满摆出倒地姿势沿抛物线落下 → 圆形转场 → 在检查点满心复活。
  - 从死亡到能重新操作不超过 1.2 秒。
  - 已打倒的敌人和顶过的砖保持原样；没打倒的敌人回到原位；贝壳和海玻璃都保留。

**3 枚海玻璃**：
1. ① 风铃旋律（探索）：A5。阿豆告诉你顺序。
2. ② 隐藏铃砖（顺路但要留心）：D2。台阶顶上方，偶尔闪微光。
3. ③ 高台（技巧）：D3 第二座岛上方 6 格。
   - 普通助跑跳最高约 4.8 格，跳不上去；按住跳跃键踩蓝钳能弹到约 6.3 格。
   - 关卡校验测试会用实测值确认这个差距。

## 4. 剧情与对白

### 序章「霜夜」（夜里的钟楼，约 40 秒）

1. 黑屏淡入：夜空和星星，镜头从高处缓缓下移到钟楼。
   - 旁白：时令岛的钟楼上，挂着一口四时大钟。
   - 旁白：每天清晨大钟一响，春、夏、秋、冬四枚时令铃就跟着共鸣，岛上的季节才能一天天流转。
2. 一阵冷风吹灭了灯火，一个高瘦的身影出现在钟楼的横梁上。
   - 霜降：花开了又谢，叶绿了又黄……年年如此，真是无趣。
   - 霜降：不如，就让季节停在最冷的那一刻吧。
   - 四枚时令铃一枚接一枚飞进他手里，每枚响一声，一声比一声弱。
3. 一只小寄居蟹从屋檐下爬过。霜降把夏铃丢给它。寄居蟹钻进夏铃里，背上结出冰晶，眼睛亮起蓝光，朝东边的海岸爬去。
   - 霜降：小东西，这枚夏铃给你当壳。替我好好看着。
4. 钟楼的门砰地打开，钟爷爷提着灯笼冲出来。
   - 钟爷爷：站住！把时令铃放下！
   - 霜降：守钟人……你也该歇歇了。
   - 霜降一挥袖，寒气扑面而来，钟爷爷被冻成了冰雕。霜降化作一阵雪花消失，冰霜从钟楼向四周蔓延。
5. 黑屏，字幕：「第二天清晨——」

### 钟楼前（进入广场自动触发，约 50 秒）

1. 镜头沿着钟楼往上移：钟楼结满了冰霜，大钟一动不动，四个挂时令铃的钩子都空了。镜头回到小满。
   - 小满：爷爷——我来啦！今天的钟怎么……
2. 小满看到冰雕，头上冒出"！"，跑了过去。
   - 小满：爷、爷爷？！你怎么冻成冰块了！
   - 小满：好冰……现在可是夏天啊！
3. 大钟里亮起一点微光，"叮——"，一个小铃铛飘了出来。
   - 回回：叮……叮！你好你好！
   - 小满：哇啊！会说话的……铃铛？
   - 回回：我是回回，大钟的回音！回音、回音！
   - 回回：昨天夜里，一个戴面具的人偷走了四枚时令铃。爷爷去拦他，就被冻住了……冻住了……
   - 小满：时令铃没了？那岛上的季节会怎么样？
   - 回回：夏天会被冰霜一点点吃掉。只有把时令铃找回来、挂回大钟上，爷爷才能化开。
   - 回回：你看，地上的冰霜脚印一直通到东边的海边……对吧对吧？
   - 小满：爷爷，你等着！包在我身上！
   - 回回：包在我身上！……啊不对，是包在你身上！我也一起去！
4. 回回飞到小满身边，之后一路跟着她。屏幕提示：沿着冰霜脚印往东走。

钟楼过场里音乐停下，只留风声；"包在我身上"之后音乐重新响起。

## 9. 风险与备选

| 风险 | 备选 |
|---|---|
| 美术量大 | 用部件拼装和换色；房屋和钟楼按规则生成；头像用"脸型 + 表情部件"拼 |
| 音乐没法试听 | 结构简单，按乐理写；试听板可以逐首试听；用户不满意就替换 |
| 浏览器画 12px 字体时有抗锯齿 | 做阈值化；还不行就看截图逐字修正 |
| Phaser 4 的模糊、去色滤镜不好用 | 退回半透明压暗、换调色板 |
| 过场让回放结果不一致 | 过场期间世界暂停；每段过场声明结束状态，播完和跳过得到同样的结果 |
| 启动时要生成的东西变多，启动变慢 | 分帧生成，期间显示启动 Logo；音乐在标题出现后再一段段合成 |
| 用户觉得难 | 缝隙尺寸保守；有辅助模式；关卡校验和回放测试兜底 |

## 10. 这次替用户定下的默认选择

会写进 PLAN §12.1。用户有不同意见随时指出。

1. **正式 UI 的像素比例**：HUD、对话、菜单都画在游戏画布里，像素比例和世界相同；练习场的辅助文字仍然用 DOM 半尺寸。
2. **文字渲染**：自己做逐字渲染（字形图集，每个字一个精灵），换行、避头尾、逐字特效都自己掌控。
3. **踩踏弹起**：按住跳跃键踩敌人的弹起速度调到约 440 px/s（见 §3）。
4. **死亡后的关卡状态**：见 §3 的死亡规则，不惩罚探索。
5. **海玻璃**：拾取就存档，再玩时显示为半透明。
6. **芒果**：满心时变成 3 枚贝壳。
7. **通关以后**：显示"第 2 关制作中"，回到标题。章节地图在 M2 做。
8. **菜单按键**：确认是跳跃键、Enter、手柄 A；返回是攻击键、Esc、手柄 B；暂停是 Esc、Enter、P、手柄 Start。
9. **教学方式**：不用文字牌子，用回回的提示气泡加屏幕下方的按键提示。
10. **音乐合成器**：纯 TypeScript，能在 Node 里测试和分析；浏览器只负责播放和混音。
11. **序章场景**：借用 1-1 的村庄地图加夜色滤镜。
12. **重玩时的过场**：照常播放，长按 Esc 可以跳过。
